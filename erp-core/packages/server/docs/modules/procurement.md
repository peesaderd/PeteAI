# Procurement Module

## Overview
วางแผนและจัดการกระบวนการจัดซื้อเชิงกลยุทธ์

## Features
- **Supplier Evaluation** — ประเมินผู้ขาย
- **Contract Management** — จัดการสัญญาซื้อขาย
- **Purchase Planning** — วางแผนการจัดซื้อ
- **Budget Control** — ควบคุมงบประมาณ

## API Endpoints
| Method | Path | Description |
|--------|------|-------------|
| GET | /api/procurement/plans | แผนการจัดซื้อ |
| POST | /api/procurement/plans | สร้างแผน |
| GET | /api/procurement/suppliers | รายการผู้ขาย |
| POST | /api/procurement/evaluate | ประเมินผู้ขาย |
