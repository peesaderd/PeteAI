# Marketing Module

## Overview
จัดการแคมเปญการตลาด โปรโมชั่น และวิเคราะห์ข้อมูลลูกค้า

## Features
- **Campaign Management** — สร้างและติดตามแคมเปญ
- **Promotion** — กำหนดโปรโมชั่นและส่วนลด
- **Customer Segmentation** — แบ่งกลุ่มลูกค้า
- **Analytics** — วิเคราะห์ผลตอบแทน (ROI)

## API Endpoints
| Method | Path | Description |
|--------|------|-------------|
| GET | /api/marketing/campaigns | รายการแคมเปญ |
| POST | /api/marketing/campaigns | สร้างแคมเปญ |
| GET | /api/marketing/analytics | ข้อมูลวิเคราะห์ |
